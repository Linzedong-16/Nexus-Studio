# Quickstart: 亮暗模式切换与丝滑过渡动画

**Feature**: `003-theme-toggle-transition` | **Date**: 2026-08-10

本指南用于在实现完成后，人工验证功能端到端可用（项目当前无自动化测试框架，验证方式为手动走查，
详见 plan.md 的 Technical Context / Testing 字段）。

## 前置条件

- 已完成 `pnpm install`
- 已按 data-model.md 与 research.md 的设计完成实现（`themeStore.ts`、`ThemeToggleButton.tsx`、
  `viewTransition.ts`、`main.css` 的 `.dark` 令牌块、`components/schema/` 下的暗色安全色阶修正、
  `SqlEditor.tsx` 的 Monaco `theme` 联动）

## 验证步骤

1. **静态检查门禁**

   ```bash
   pnpm run typecheck
   pnpm run lint
   pnpm run format
   ```

   预期：三项均无报错（对应宪法要求的质量门禁）。

2. **启动应用**

   ```bash
   pnpm run dev
   ```

   预期：应用以浅色主题启动（首次运行 / 无历史记录时的默认值，对应 data-model.md 的初始化规则）。

3. **验证 User Story 1（一键切换）**
   - 在顶部栏搜索按钮右侧确认出现新的亮暗模式切换图标（FR-001）。
   - 点击该图标：确认标题栏、侧边栏、结构树、内容区、对话框等全部区域在 1 秒内整体切换为暗色
     （SC-001），图标自身的视觉状态同步改变（FR-009）。
   - 再次点击：确认整体切换回浅色。
   - 关闭应用并重新执行步骤 2：确认应用直接以上次选择的主题呈现，而非回退到默认浅色（SC-004）。

4. **验证 User Story 2（暗色下无内容消失）**
   - 切换到暗色模式后，依次检查：
     - 侧边栏结构树的服务器 / 数据库 / Schema / 表 / 索引 / 触发器等各级节点的图标与文字
     - 表节点展开后的主键列名（`text-amber-700` 修正点）、PK/UNIQUE 徽章
     - 安全（角色/用户）节点的图标与徽章
     - 设置面板、连接表单、下拉菜单等浮层组件的背景与文字
     - 打开一个 SQL 编辑器标签页，确认编辑器背景、文字与语法高亮同步为深色配色（`vs-dark`）
   - 抽查不少于 20 处文字/图标元素，确认每一处都清晰可辨、无颜色覆盖导致的"消失"现象（SC-002）。

5. **验证 User Story 3（扩散动画）**
   - 点击切换图标，观察扩散效果是否以图标所在屏幕位置为圆心向四周扩散，直至覆盖整个窗口
     （FR-005），过程中无明显卡顿或残留色块（FR-006 / SC-003）。
   - 动画播放期间快速连续点击图标多次：确认不出现界面撕裂、主题状态错乱或动画堆积卡死
     （FR-008）。
   - 将窗口最大化/还原后再次点击切换图标：确认扩散范围正确适配当前窗口尺寸（不出现覆盖不全
     或超出窗口的情况）。
   - 在操作系统设置中开启"减弱动态效果”（Windows：设置 → 辅助功能 → 视觉效果 → 动画效果关闭），
     重新点击切换图标：确认直接完成切换、不播放扩散动画（FR-007 / SC-005）。

6. **验证无障碍激活方式**
   - 仅使用 Tab 键将焦点移动到切换图标，确认可以聚焦（FR-010）。
   - 聚焦后按 Enter/Space 激活，确认主题正常切换。
   - 使用屏幕阅读器（如 Windows 讲述人）聚焦该图标，确认能读出清晰的文本说明（当前主题/操作
     意图）。

7. **回归检查**
   - 确认既有的连接管理、结构树展开/折叠、全局搜索等功能在两种主题下均正常工作，未受本次改动
     影响。
