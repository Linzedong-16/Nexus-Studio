# Quickstart: 外壳骨架手动验证指南

本指南验证 001-app-shell-ui 交付后应用端到端可用，覆盖 spec.md 全部 Success Criteria。类型/静态检查先行，功能走查随后。实现细节见 [plan.md](plan.md)；接口约定见 [contracts/](contracts/)。

## 前置条件

```bash
pnpm install          # 含新增依赖 react-router 与 shadcn 增补组件的 Radix 包
pnpm run typecheck    # 必须零错误（宪法质量门禁）
pnpm run lint         # 必须零错误
pnpm run dev          # 启动应用
```

## 场景 1：脚手架清理验证（FR-025）

1. 确认以下文件不存在：`src/renderer/src/components/Versions.tsx`、`src/renderer/src/assets/electron.svg`、`src/renderer/src/store/counter.ts`
2. `src/main/index.ts` 中无 `ping` IPC 测试代码
3. 启动后界面**只有**外壳布局，无任何 Electron/Vite 演示元素（logo、计数器、版本号）
4. ✅ 预期：窗口呈现 TRAE 风格三区布局，无演示样式残留

## 场景 2：三模式切换与独立路由（SC-001，对应 US1）

1. 观察侧边栏顶部：Work / `</>` Code / Design 分段切换器，当前项有高亮指示块
2. 依次点击三个模式标签
3. ✅ 预期：指示块 200–250ms 内平滑滑动到目标标签；侧边栏菜单随模式切换；内容区渲染对应模式占位首页（Code 首页含居中大标题 + 输入框骨架 + 快捷按钮组）；三模式首页文案可明确区分
4. 在地址层面验证：`/#/work`、`/#/code`、`/#/design` 均直达对应模式首页
5. 访问 `/#/code/xxx`（无效子页）→ 回退 `/#/code`；访问 `/#/nope`（无效模式）→ 回退默认模式首页
6. ✅ 预期：无白屏、无未捕获错误（SC-006）

## 场景 3：模式与折叠态持久化（SC-002，FR-008/012）

1. 切换到 Design 模式，折叠侧边栏，**完全退出应用后重新启动**
2. ✅ 预期：启动即恢复 Design 模式 + 侧边栏折叠态
3. 清除站点数据后启动 → 恢复默认（Work 模式 + 展开态）

## 场景 4：侧边栏折叠动画与窄栏可用性（SC-002，对应 US2）

1. 点击顶栏最左侧折叠按钮
2. ✅ 预期：侧边栏在 ≤300ms 内收起为 ~56px 图标窄栏（菜单文字消失、图标保留），内容区平滑扩展，无跳变/抖动
3. 折叠态下：悬停图标有 tooltip；点击模式/菜单图标导航仍可用；底部用户区收缩为仅头像
4. 再次点击折叠按钮 → 展开还原 ~260px
5. 窗口最大化状态下重复 1–4，动画表现一致

## 场景 5：顶部全局控件（对应 US2）

1. 点击搜索图标 → 居中搜索面板弹出（含输入框占位）；按 `Esc` 或点击遮罩 → 关闭
2. 打开搜索面板后点击任一模式标签 → 面板关闭且模式切换生效
3. 点击"编辑(E)" → 下拉菜单骨架（撤销/重做/剪切/复制/粘贴占位项）；点击"帮助(H)" → 下拉菜单骨架（关于/快捷键占位项）；点击菜单外区域关闭
4. ✅ 预期：全部为纯展示骨架，有 hover/焦点视觉反馈，无真实业务行为

## 场景 6：无边框窗口控制（FR-002/003，契约见 contracts/ipc-window.md）

1. 顶栏空白区按住拖拽 → 窗口跟随移动；双击拖拽区 → 最大化/还原
2. 右上角三按钮：最小化 → 任务栏；最大化 → 图标切换为还原态且内容区自适应；再次点击还原
3. 用系统方式还原（如 Win+↓）→ 窗口还原且按钮图标同步（验证 `window:maximized-changed` 事件）
4. 拖拽窗口边缘缩小 → 到达最小尺寸（约 940×600）后不可继续缩小，布局不崩溃
5. 关闭按钮 → 应用正常退出

## 场景 7：配置驱动扩展性抽查（SC-004，FR-010）

1. 在 `config/modes.tsx` 某模式 `routes` 临时追加一条测试路由 + 对应 `MenuItem`
2. ✅ 预期：新页面可经侧边栏菜单访问，**未修改** `AppShell.tsx` / `router.tsx` / 侧边栏任何组件；验证后回滚该临时改动

## 场景 8：视觉走查（SC-005）

对照 TRAE 参考截图逐项比对：

| #   | 要点          | 通过标准                                                                            |
| --- | ------------- | ----------------------------------------------------------------------------------- |

## 故障排查

| 症状                   | 排查                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| 生产构建后路由直达白屏 | 确认使用 `createHashRouter` 而非 BrowserRouter（research.md R-001）                              |
| 窗口控制按钮无响应     | DevTools 检查 `window.api.windowControls` 是否暴露；主进程 `window:*` 处理器是否注册             |
| 折叠态重启未恢复       | DevTools → Application → Local Storage 检查 `shell-store` 键；确认 persist `partialize` 含该字段 |
| 拖拽区不可拖拽         | 检查标题栏容器 `-webkit-app-region: drag` 与按钮 `no-drag` 是否被 Tailwind 类覆盖                |
