### 二、项目目录结构

```
src/
  main/                    # 主进程 (Electron Main Process)
    config/                # 配置持久化 (electron-store, 加密, 快捷键)
    db/                    # 数据库驱动层
      core/                # 驱动接口定义 + DriverManager
      driver/pg/           # PostgreSQL 驱动实现
      factory.ts           # 驱动工厂
    ipc/                   # IPC 通信模块 (9 个文件)
    logger/                # 数据库日志器
    index.ts               # 主进程入口
  preload/                 # 预加载脚本 (contextBridge 暴露 API)
  renderer/                # 渲染进程 (React)
    src/
      components/          # 组件 (common / er / layout / schema / settings / ui / work)
      config/              # 模式配置 + 数据库能力配置
      lib/                 # 工具库 (keybinding / theme / monaco / utils)
      pages/               # 页面级组件 (work / code / design)
      router/              # 路由表
      services/            # 服务层 (configService / queryService)
      store/               # Zustand 状态管理 (8 个 store)
      types/               # TypeScript 类型定义
```
