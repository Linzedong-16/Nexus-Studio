# DB-Client 开发阶段划分与实施计划

## 1. 总体阶段概览

```
Phase 1            Phase 2            Phase 3            Phase 4
[基础框架]  ────>  [PG 核心]  ────>  [高级功能]  ────>  [AI 集成]
  2-3 周            3-4 周            2-3 周            3-4 周
```

| 阶段 | 名称 | 周期 | 核心目标 |
|------|------|------|----------|
| Phase 1 | 基础框架搭建 | 2-3 周 | 完善项目骨架、UI 布局、基础组件 |
| Phase 2 | PostgreSQL 核心功能 | 3-4 周 | 连接管理、SQL 编辑、查询执行、结果展示 |
| Phase 3 | 高级功能 | 2-3 周 | 数据导入导出、Schema 浏览器、查询历史、多标签页 |
| Phase 4 | AI 智能集成 | 3-4 周 | 自然语言转 SQL、智能补全、数据分析、AI 对话 |

---

## 2. Phase 1：基础框架搭建（第 1-3 周）

### 2.1 目标

完成项目基础设施搭建，建立可扩展的项目骨架，实现应用基本 UI 布局。

### 2.2 任务分解

#### 第 1 周：项目基础完善

| 任务 | 描述 | 产出 |
|------|------|------|
| 1.1 目录结构重构 | 按架构方案建立完整目录结构 | 完整 src/ 目录树 |
| 1.2 路径别名配置 | 配置 `@/`、`@renderer/` 别名 | tsconfig 更新 |
| 1.3 基础 UI 组件安装 | 通过 shadcn/ui CLI 安装所需组件 | Button, Input, Dialog, Select, Tabs, DropdownMenu, Tooltip, ScrollArea, Separator, Badge, Card, Table 等 |
| 1.4 全局样式与主题 | 配置 Tailwind 主题变量、亮/暗色模式 | 主题 CSS 变量、暗色模式切换 |
| 1.5 应用布局框架 | 实现 AppShell、Sidebar、StatusBar | 基础布局骨架 |

#### 第 2 周：核心组件框架

| 任务 | 描述 | 产出 |
|------|------|------|
| 2.1 侧边栏导航 | 数据库连接列表、功能导航 | Sidebar 组件 |
| 2.2 标签页系统 | 多标签页管理、切换、关闭 | TabBar + TabContext |
| 2.3 面板布局 | 可拖拽调整大小的面板布局 | 基于 react-resizable-panels 的面板 |
| 2.4 状态栏 | 连接状态、数据库信息、快捷操作 | StatusBar 组件 |
| 2.5 菜单栏与快捷键 | 应用菜单、键盘快捷键注册 | Electron Menu 配置 |

#### 第 3 周：IPC 通信与主进程基础

| 任务 | 描述 | 产出 |
|------|------|------|
| 3.1 IPC 框架搭建 | 建立 IPC 注册/分发机制 | IPC 基础框架 |
| 3.2 preload API 暴露 | 定义并暴露 electronAPI | preload/index.ts 更新 |
| 3.3 类型声明完善 | 全局类型声明和接口定义 | *.d.ts 文件 |
| 3.4 日志系统 | 集成 electron-log | 日志配置 |
| 3.5 凭据加密存储 | safeStorage 集成 | 密码加密工具 |

### 2.3 依赖安装清单

```bash

```

### 2.4 Phase 1 验收标准

- [ ] 应用可正常启动，显示完整 UI 布局
- [ ] 侧边栏、主内容区、状态栏渲染正常
- [ ] 支持亮/暗色模式切换
- [ ] 多标签页可正常创建、切换、关闭
- [ ] 面板可拖拽调整大小
- [ ] IPC 通信通道可正常调用
- [ ] 日志系统正常工作

## 3. Phase 2：PostgreSQL 核心功能（第 4-7 周）

### 3.1 目标

实现 PostgreSQL 数据库的完整连接管理和 SQL 查询功能，提供可用的数据库客户端核心体验。

### 3.2 任务分解

#### 第 4 周：数据库连接管理

| 任务 | 描述 | 产出 |
|------|------|------|
| 4.1 PostgreSQL 适配器 | 实现 `pg` 驱动的连接、断开、测试 | PostgreSQLAdapter 类 |
| 4.2 连接池管理 | 实现 ConnectionManager，多连接管理 | ConnectionManager 类 |
| 4.3 连接配置持久化 | 连接信息保存到本地 JSON 文件 | 连接配置读写 |
| 4.4 连接对话框 UI | 新建/编辑连接的对话框 | ConnectionDialog 组件 |
| 4.5 连接列表 UI | 侧边栏连接列表展示 | ConnectionList 组件 |
| 4.6 连接状态指示 | 连接中/已连接/断开/错误状态 | 状态指示器 |

#### 第 5 周：SQL 编辑器

| 任务 | 描述 | 产出 |
|------|------|------|
| 5.1 Monaco Editor 集成 | 加载 Monaco Editor，配置 SQL 语言 | SqlEditor 组件 |
| 5.2 SQL 语法高亮 | 配置 PostgreSQL 语法高亮规则 | Monaco 语言配置 |
| 5.3 SQL 自动补全 | 基础关键字补全、表名/列名补全 | 补全提供器 |
| 5.4 编辑器工具栏 | 执行/停止/格式化/导出按钮 | EditorToolbar 组件 |
| 5.5 快捷键绑定 | Ctrl+Enter 执行、Ctrl+Shift+F 格式化 | 快捷键配置 |
| 5.6 SQL 格式化 | 集成 sql-formatter 进行 SQL 美化 | 格式化功能 |

#### 第 6 周：查询执行与结果展示

| 任务 | 描述 | 产出 |
|------|------|------|
| 6.1 查询执行流程 | IPC 调用 → 主进程执行 → 返回结果 | 完整查询链路 |
| 6.2 查询结果表格 | 使用 TanStack Table 展示结果 | ResultTable 组件 |
| 6.3 查询状态管理 | loading/error/success 状态 | queryStore 完整实现 |
| 6.4 查询取消 | 支持取消长时间运行的查询 | 取消功能 |
| 6.5 查询耗时统计 | 显示查询执行时间 | 耗时显示 |
| 6.6 错误处理与展示 | 友好的错误信息展示 | 错误面板 |
| 6.7 结果分页 | 大数据集分页加载 | ResultPagination 组件 |

#### 第 7 周：Schema 浏览与查询历史

| 任务 | 描述 | 产出 |
|------|------|------|
| 7.1 Schema 树 | 数据库 → Schema → 表 → 列的树形结构 | SchemaTree 组件 |
| 7.2 表详情面板 | 列信息、索引、约束展示 | TableDetail 组件 |
| 7.3 查询历史 | 本地存储查询历史记录 | QueryHistory 组件 |
| 7.4 快捷 SQL 生成 | 右键菜单生成 SELECT/INSERT 等模板 | 上下文菜单 |
| 7.5 连接信息展示 | 当前连接的数据库/版本/状态 | 连接信息面板 |

### 3.3 依赖安装清单

```bash
# Phase 2 新增依赖
pnpm add pg                                  # PostgreSQL 驱动
pnpm add @types/pg -D                        # PG 类型声明
pnpm add sql-formatter                       # SQL 格式化
pnpm add node-sql-parser                     # SQL 解析
pnpm add uuid                                # 唯一 ID 生成
pnpm add @types/uuid -D                      # UUID 类型声明
```

### 3.4 Phase 2 验收标准

- [ ] 可创建、编辑、删除 PostgreSQL 连接
- [ ] 连接测试功能正常，错误提示友好
- [ ] SQL 编辑器支持语法高亮和关键字补全
- [ ] 可执行 SQL 查询并正确展示结果
- [ ] 支持取消正在执行的查询
- [ ] 结果集支持分页浏览
- [ ] Schema 树可正确展示数据库结构
- [ ] 查询历史可查看和复用
