## 一、整体布局结构

采用经典 IDE 三段式布局：顶部标签栏 + 左侧可折叠侧边栏 + 右侧主内容区 + 底部状态栏，整体占满视口（h-screen），无外部滚动条，各区域独立滚动。

```
┌──────────────────────────────────────────────────────┐
│  顶部标签栏（TabBar）                   [主题切换]     │
├────────┬──────────────────────────────┬───────────────┤
│ 连接列表 │  SQL 编辑器（上半部分）       │ Schema 浏览器  │
│        │                              │               │
│ 🟢 生产库│─────────────────────────────│  📦 public    │
│ 🟡 测试库│  查询结果表格（下半部分）      │   📋 users   │
│        │                              │   📋 orders  │
├────────┴──────────────────────────────┴───────────────┤
│  🟢 已连接 | PostgreSQL 16.2 | UTF-8          v1.0.0 │
└──────────────────────────────────────────────────────┘
```

具体要求：

- 整体使用 `h-screen flex flex-col` 占满视口
- 左侧栏宽度默认 260px，可折叠为 48px（仅图标模式），使用 `react-resizable-panels` 的 Panel 组件实现
- 右侧 Schema 面板默认 280px，可通过 `PanelResizeHandle` 拖拽调整
- 主内容区上下分为编辑器（上）和结果表格（下），通过横向 PanelResizeHandle 拖拽调整比例
- 所有面板的拖拽手柄样式：宽 2px，hover 时变为蓝色，带 0.2s 过渡

## 二、顶部标签栏（TabBar）

### 1. connectionStore

```typescript
interface ConnectionStore {
  connections: ConnectionConfig[] // 连接列表
  activeId: string | null // 当前活跃连接
  sidebarCollapsed: boolean // 侧边栏是否折叠
  toggleSidebar: () => void // 切换折叠
  addConnection: (config: ConnectionConfig) => void
  setActive: (id: string) => void
}
```

- 模拟数据：3 条连接配置

### 2. editorStore

```typescript
interface EditorStore {
  tabs: EditorTab[] // 标签页列表
  activeTabId: string | null
  addTab: (tab?: Partial<EditorTab>) => string
  removeTab: (id: string) => void
  setActiveTab: (id: string) => void
  updateContent: (id: string, content: string) => void
}
```

- 初始状态：无标签，显示欢迎页
- 点击「新建连接」时创建第一个标签

### 3. queryStore

```typescript
interface QueryStore {
  results: Record<string, QueryResult>
  isLoading: Record<string, boolean>
  setResult: (tabId: string, result: QueryResult) => void
  setLoading: (tabId: string, loading: boolean) => void
}
```
